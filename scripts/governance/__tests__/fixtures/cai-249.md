## OpenSpec

**Change ID:** `p1-07-pipeline-run-slice`
**Depends on:** P1-05, P1-06

## Problem

Independent scripts need one resumable, deadline-aware cloud entry point.

## Required behavior

Implement the slice contract and stage order from the Phase 1 plan with leases, heartbeats, checkpoints, summaries, and status codes.

## Interfaces

`pipeline:run-slice` CLI, stage adapter contract, and structured summary.

## Failure, security, and cost

Recoverable stage failures pause and resume. Terminal configuration failures stop before paid work. Logs are redacted, production caps are enforced, and no secret-bearing artifacts are emitted.

## Out of scope

Tavily, email transport, and final budget enforcement.

## Given/When/Then test specification

### Unit

GIVEN stage outcomes, deadlines, and heartbeat states, WHEN orchestration evaluates the next action, THEN it selects the specified status and stage order.

### Integration

GIVEN real run repositories and fixture stage adapters, WHEN a slice pauses or fails recoverably, THEN progress and error state persist at the last committed unit.

### E2E

GIVEN a multi-stage backlog, WHEN one process is terminated and later slices resume, THEN the run eventually completes with a coherent summary.

## Acceptance criteria

- [ ] A slice completes, pauses, or fails with a persisted reason.
- [ ] Backlog remaining is a successful resumable outcome.
- [ ] A killed-run recovery test passes.
- [ ] OpenSpec artifacts are valid and synchronized with this issue.
- [ ] Unit, repository integration, killed-run E2E, and regression tests pass.
- [ ] `/opsx:verify` and commit-bound `verify:pr-ready` pass before PR creation.
- [ ] Post-open CI and adversarial review pass before merge.
