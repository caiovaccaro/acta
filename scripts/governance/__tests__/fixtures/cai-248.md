## Problem

The current Vercel deployment fails after repository cleanup. Local evidence shows non-production `NODE_ENV` causes broad prerender failure, while output paths may also disagree.

## Required behavior

Use deployment logs to identify the actual failure, reject non-production build environment, define one supported Vercel output contract, and verify required routes.

## Interfaces

Vercel configuration, Next.js configuration, production-environment assertion, and deploy smoke command.

## Failure, security, and cost

Build or route mismatch fails before promotion; the previous deployment remains available. Smoke tests expose no admin credentials and remain inside Vercel Hobby limits.

## Out of scope

Database migration and pipeline scheduling.

## Given/When/Then test specification

### Unit

GIVEN Vercel, Next.js, and build-environment settings, WHEN configuration validation runs, THEN non-production `NODE_ENV` and mismatched output paths are rejected.

### Integration

GIVEN a clean Linux monorepo with `NODE_ENV=production`, WHEN the Next.js build runs, THEN workspace packages and Prisma resolve without local-only paths or prerender errors.

### E2E

GIVEN a preview deployment, WHEN smoke tests request health, homepage, topic, question, and admin login, THEN every route returns its expected status and content marker.
