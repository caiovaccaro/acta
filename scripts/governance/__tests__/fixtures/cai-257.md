## OpenSpec

**Change ID:** `p1-14-production-pipeline-workflow`
**Depends on:** P1-04, P1-07, P1-09, P1-13

## Problem

The resumable runner needs unattended cloud scheduling and a safe manual trigger.

## Required behavior

Configure six-hour triggers, dispatch inputs, read-only permissions, a 330-minute timeout, dependency installation, migration deployment, and slice execution.

## Interfaces

Production GitHub Actions workflow and documented secret contract.

## Failure, security, and cost

Overlap exits through concurrency and lease controls. Native GitHub failure remains available if application email cannot send. No secret output or sensitive artifacts; use only standard public runners.

## Out of scope

Self-hosted or paid larger runners.

## Given/When/Then test specification

### Unit

GIVEN workflow YAML and dispatch inputs, WHEN schema and policy validation run, THEN only read-only permissions, bounded timeouts, and safe inputs pass.

### Integration

GIVEN a fixture Actions environment with PostgreSQL and mocked providers, WHEN workflow commands execute, THEN setup, migration, and one slice complete without secret output.

### E2E

GIVEN a manual dispatch against a disposable hosted database, WHEN the workflow runs, THEN a capped slice persists progress and sends its receipt.
