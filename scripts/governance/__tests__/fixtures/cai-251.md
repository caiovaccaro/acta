## OpenSpec

**Change ID:** `p1-08-llm-usage-ledger`
**Depends on:** P1-05

## Problem

Console cost logs cannot support audit, reporting, or budget enforcement.

## Required behavior

Record model, operation, tokens, estimated cost, run, and stage from the central provider.

## Interfaces

Provider usage callback and `LlmUsage` repository.

## Failure, security, and cost

Usage persistence failure is visible and blocks further paid requests for that slice to avoid unaccounted spend. Never store prompts, completions, API keys, or article text in the ledger.

## Out of scope

Rejecting calls by budget.

## Given/When/Then test specification

### Unit

GIVEN model pricing and token usage, WHEN cost is calculated and mapped, THEN fixed-precision cost and redacted metadata are correct.

### Integration

GIVEN one successful mocked provider response, WHEN the provider completes, THEN exactly one usage row links to its run, stage, operation, and model.

### E2E

GIVEN a capped fixture analysis, WHEN the slice finishes, THEN its email/run summary includes the same ledger cost without storing prompt content.

## Acceptance criteria

- [ ] Every successful provider call records tokens, model, operation, and estimated cost.
- [ ] Sensitive request and response content is not stored in the ledger.
- [ ] OpenSpec artifacts are valid and synchronized with this issue.
- [ ] Unit, provider integration, run-summary E2E, and regression tests pass.
- [ ] `/opsx:verify` and commit-bound `verify:pr-ready` pass before PR creation.
